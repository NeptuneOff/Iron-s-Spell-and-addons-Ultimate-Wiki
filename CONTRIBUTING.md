# Contributing / Contribuer

Les corrections factuelles sont bienvenues. Toute modification de donnée doit indiquer le mod, la version, l'identifiant de registre et la source vérifiable (classe, recette, table de butin ou fichier worldgen).

Factual corrections are welcome. Any data change must identify the mod, version, registry ID and verifiable origin (class, recipe, loot table or worldgen file).

Do not commit third-party JARs, decompiled source code, or extracted textures.
