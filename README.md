## Français

Wiki interactif bilingue pour **Minecraft 1.21.1**, **NeoForge 21.1.250**, avec les configurations par défaut du modpack de NeptuneOff.

Le site réunit les écoles, sorts, équipements, enchantements, entités, structures, méthodes d'obtention et un créateur de setup hybride : assistant guidé ou composition libre, avec une à deux écoles.

### Périmètre audité

- Cataclysm Spellbooks `1.1.14`
- Discerning the Eldritch `1.4.4`
- HazentouveLib `1.0.9` et Hazen N Stuff `1.4.0.14`
- Iron's Spells: Magic From The East `1.1.5`

- Dark Doppelganger `3.4.0`
- Create: Wizardry `0.5.1-pre1`
- Somake's Spells `1.0.8-fix`

Les dépendances de contenu — notamment L_Ender's Cataclysm, Deeper and Darker, Born in Chaos et Create — sont identifiées séparément des addons magiques. Les mods purement techniques du serveur ne sont pas présentés comme du contenu Iron's Spells.

### Fiabilité des données

Le catalogue est généré depuis les JAR exacts du modpack, sans redistribuer leur code ni les JAR eux-mêmes. Un atlas limité aux icônes d'objets et de runes est utilisé à des fins d'identification visuelle dans le wiki. Chaque mod reçoit un état de provenance :

- **source exacte** : dépôt et version installée correspondent ;
- **JAR exact, dépôt en retard** : les valeurs du JAR installé priment ;
- **JAR uniquement** : aucun dépôt public fiable n'a été trouvé.

Les traductions françaises officielles sont conservées. Lorsqu'un addon ne fournit que l'anglais, le texte anglais reste visible dans l'interface française afin de ne pas fabriquer une traduction technique trompeuse.

### Développement local

Le site ne nécessite aucun build : servez simplement le dossier `docs/`.

```bash
npm run serve
```

La commande d'extraction est réservée à la maintenance et attend les JAR autorisés dans le dossier de travail local ; ceux-ci ne sont jamais commités.

```bash
npm run extract
npm run check
```

## English

Interactive bilingual wiki for **Minecraft 1.21.1**, **NeoForge 21.1.250**, using the modpack's default configuration.

It covers schools, spells, gear, enchantments, entities, structures, acquisition paths, and a hybrid build creator: guided recommendations or free composition with one or two schools.

The catalogue is generated from the modpack's exact JAR files without redistributing their code or the JARs themselves. A limited atlas of item and rune icons is used for visual identification in the wiki. Official French translations are used where available; untranslated addon content retains its original English text.
